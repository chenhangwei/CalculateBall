# CalculateApp 气球飞艇计算软件 

## 📋 程序说明

这是一个专业的气球和飞艇浮力计算软件，支持实时计算功能。

## 🚀 快速开始

### 方法一：Python源码运行（推荐）
1. 确保已安装Python 3.7或更高版本
2. 双击 `启动程序.bat`
3. 程序会自动安装必要的依赖库并启动

### 方法二：直接运行
```bash
python CalculateApp.py
```

## 📦 依赖要求

程序需要以下Python库：
- PyQt5 >= 5.15.0
- numpy >= 1.20.0  
- scipy >= 1.7.0
- sqlite3 (Python内置)

## ✨ 主要功能

### 实时计算特性
- ✅ **自动计算**: 输入参数后自动计算结果
- ✅ **实时更新**: 修改任意参数立即更新所有相关结果
- ✅ **简洁界面**: 隐藏计算按钮，界面更清爽

### 球体计算
- 体积和浮力计算
- 净浮力计算（包含客户负载）
- 与地面夹角计算
- 其他重量支持

### 飞艇计算
- 椭球体积计算
- 浮力和重量分析
- 完整的几何参数计算

### 数据库查询
- 风压数据查询
- 膜材参数查询
- 缆绳规格查询
- 管材信息查询

## 🔧 技术特性

### 实时计算系统
- 31个输入控件全部支持实时计算
- 文本框和下拉框变化事件自动触发
- 智能默认值设置

### 数据管理
- SQLite数据库存储
- 完整的椭球参数数据
- 多种材料和规格数据

## � Word 研究报告与数据文件

- **导出报告**：打开“导出报告”页，选择气球/飞艇，填写报告信息，点击“导出 Word 报告…”，生成 `.docx` 研究报告。报告含封面、摘要与指标一览、目录、概述、设计输入、计算方法与公式、结果与图表（外形、风廓线、浮力瀑布图、受力姿态、风速敏感性、选型曲线）、强度校核、结论与建议、完整参数附录。目录在 Word 打开时自动更新（提示更新域时选“是”）。
- **保存/打开数据**：每个计算页顶部的“保存数据”把该页全部输入存成文本文件（`.txt`，内容为 JSON，可用记事本查看）；“打开数据”读回并重新计算，文件属于另一类浮空器时自动切换页面。
- 依赖 `python-docx`（见 `requirements.txt`）。

## 🎯 使用说明

1. **启动程序**: 运行 `启动程序.bat`
2. **选择页面**: 点击"球体"或"飞艇"标签
3. **输入参数**: 在相应输入框中输入数值
4. **查看结果**: 结果会自动实时更新显示
5. **查询数据**: 使用相应的查询按钮查看材料参数

## ⚠️ 注意事项

- 首次运行可能需要几分钟安装依赖库
- 确保网络连接良好以便下载依赖
- 所有数据文件必须保持在程序目录下
- 支持Windows 10/11系统
